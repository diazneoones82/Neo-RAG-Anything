# Neo RAG-Anything

Neo RAG-Anything is a local Windows document RAG app for indexing documents,
searching retrieved context, and asking grounded questions through a browser GUI
or desktop launcher.

This public repository is for release downloads only. Source code and build
instructions are not distributed from this repository.

## Download

Download the Windows package from the release page:

https://github.com/diazneoones82/Neo-RAG-Anything/releases/tag/v1.0.0

Package:

```text
Neo-RAG-Anything-Windows.zip
```

## What It Does

Neo RAG-Anything helps you work with local document collections on Windows. It
can index supported files, retrieve relevant chunks, and produce grounded
answers with references back to the indexed material.

Core capabilities:

- Local document search and retrieval
- Browser-based GUI on `127.0.0.1`
- Native Windows launcher
- Local extractive answers
- Optional model-assisted answers when configured
- Import of prepared ingest data

## Free Version Notes

This free release is a packaged application build with selected advanced ingest
and export controls disabled. The full-feature package is distributed
separately from the owner.

## How To Use

1. Download the release ZIP.
2. Extract it to a normal Windows folder.
3. Run:

```text
Neo RAG-Anything.exe
```

The launcher starts the local GUI service and opens:

```text
http://127.0.0.1:7860
```
